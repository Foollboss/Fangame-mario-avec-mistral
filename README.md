## Supersonic Arena

Le dossier [`rocket-arena/`](rocket-arena/) contient **Supersonic Arena**, un jeu de foot en voitures à réaction inspiré de
Rocket League, jouable sur PC Windows ([`rocket-arena/SupersonicArena.exe`](rocket-arena/SupersonicArena.exe), ou
`rocket-arena/index.html` dans un navigateur) et sur Android
([`rocket-arena/SupersonicArena.apk`](rocket-arena/SupersonicArena.apk)). Détails et commandes dans
[`rocket-arena/README.md`](rocket-arena/README.md).
