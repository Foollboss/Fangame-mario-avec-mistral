# Teyvat Pixel — fan-game pixel-art inspiré de Genshin Impact

Une version **pixel-art** de la moitié du jeu *Genshin Impact* (mobile), avec l'interface de la capture d'écran
d'origine (mini-carte, rang d'aventure, équipe de 4, boutons d'action, barre de PV, UID, ping…).

> Projet de fan non officiel, sans lien avec HoYoverse. Aucun asset original n'est utilisé : tous les
> graphismes (tuiles, personnages, icônes, police) et les sons sont **générés par code**.
